# Networking

## Overview

This section documents my learning journey in computer networking, with a focus on understanding network protocols, analyzing network traffic, and applying networking concepts to cybersecurity investigations.

Through cybersecurity training activities and practical exercises, I aim to develop the foundational networking knowledge required to identify, investigate, and troubleshoot network-related security incidents.

## 1. Learning Objectives

- Understand the fundamentals of computer networking and TCP/IP.
- Learn the functions of common network protocols, including TCP, UDP, DNS, HTTP, and ICMP.
- Understand IP addressing, ports, and network communication.
- Analyze network traffic and interpret protocol-related errors.
- Develop foundational network troubleshooting and incident investigation skills.
